# GlowTact Website Design System

## Direction
Modern robotics research page:
- clean
- minimal
- technical
- high contrast
- spacious
- grounded in real experimental imagery

Reference:
https://younghyopark.me/tune-to-learn/

Use the reference only for hierarchy, whitespace, wide visuals, and interactive scientific storytelling. Do not copy its design.

## Colors
Background:
- `#FFFFFF`
- `#F6F6F3`
- dark section `#111111`

Text:
- `#171717`
- secondary `#5F6368`
- inverse `#F8F8F8`

GlowTact:
- amber `#E9A000`
- light amber `#FFF2CC`
- tactile dark `#27231F`

GelSight:
- blue `#0879B9`

Do not add unrelated decorative colors.

## Typography
- Geist or Inter for body
- optional restrained serif for the title
- title: 52–72 px desktop, 36–44 px mobile
- body: 17–19 px, line height around 1.6
- reading width: 760 px
- visual width: up to 1200 px

## Layout
- narrow text, wide figures
- generous vertical spacing
- avoid dashboard density
- avoid excessive cards
- preserve scientific figure aspect ratios

## Motion
Allowed:
- subtle fades
- controlled scroll reveals
- slider-driven mechanism changes
- smooth figure transitions

Avoid:
- decorative parallax
- scroll hijacking
- exaggerated springs
- constant pulsing
- flashy gradients

Respect `prefers-reduced-motion`.

## Controls
Use native, accessible controls:
- sliders
- segmented selectors
- buttons
- select menus

All controls need visible labels, keyboard access, focus states, and mobile support.

## Scientific Presentation
- preserve axes, labels, units, and log scales
- GlowTact remains amber; GelSight remains blue
- distinguish measured and simulated imagery
- use exact data for interactive plots
- label conceptual visualizations clearly

## Required Mechanism Note
> Conceptual visualization. Geometry and optical paths are schematic and are not a calibrated mechanical or ray-tracing simulation.

## Tone
Scientific, confident, restrained.

Avoid:
- “best”
- “perfect”
- “revolutionary”
- unsupported superiority claims
